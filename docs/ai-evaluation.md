可靠性测试使用本地 HTTP 模拟服务，不依赖真实供应商：覆盖正常结构、未知分类、非法 JSON、失败降级、连续失败熔断和恢复探测；MySQL 并发测试验证两个服务对象共享每居民 60 秒 5 次限额，以及八个并发恢复请求仅放行一个探测。旧探测结果不能覆盖更新的熔断状态。采纳关联测试覆盖本人成功记录、重复使用、他人记录、降级记录及最终提交字段脱敏。

默认配置：`AI_FAILURE_THRESHOLD=3`、`AI_COOLDOWN_SECONDS=60`、`AI_RETENTION_DAYS=30`。限流和熔断均持久化在 MySQL，数据库事务只用于准入和状态更新，不覆盖外部 HTTP 等待。此测试尚不等于多个独立应用进程的负载或故障切换验收。
