## 本轮修复

- MinIO 多实例首次建桶只忽略“已属于当前账号”，权限等其他错误继续失败。
- 存储客户端限制连接/读写/整体调用超时，MinIO 中断由原来的长时间等待及网关 504 改为业务 503；恢复后上传下载正常。
- Gateway 保留入口 Host，使签名图片地址可由浏览器从外部入口打开，不再返回内部容器主机名。
- outbox 领取增加 attempts 比较，防止旧查询快照误领已经进入新一轮租约的记录。
- 统计接口合并关闭数/待处理数/平均耗时扫描，按天/分类聚合后再连接字典，同一批小结果生成趋势、分类和新工单数。保持实时查询与原统计口径，新增 MySQL 用例验证上海时区半开日期边界、不同统计时间口径、小区隔离和 SLA 去重计数。
- 维护任务间隔可配置以便验收，正常默认值保持不变；没有修改任何已执行 Flyway 迁移，也没有新增结构迁移。
