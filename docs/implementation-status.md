数据库和复杂事务使用 MyBatis 参数绑定 SQL 执行，SQL 文本只在服务端定义，不接收客户端 SQL；MyBatis-Plus 提供 Spring Boot 3 的 Mapper 集成。Spring Cloud 目前由独立的注册中心、网关和一个按业务包划分的服务组成；后者尚未进一步拆成独立数据域。网关以 Eureka 发现业务实例并转发，JWT 与小区范围由业务服务校验。

本地文件模式只允许在显式开启演示模式时使用；生产仍按计划使用私有 MinIO。认证撤销直接查 MySQL；Redis 暂未接入核心路径，避免缓存故障导致越权。SLA 增加 response_started_at 字段，明确保存每轮响应起算点。

2026-10-22 修复电脑端访问及部署密码配置：开发前端默认同源代理到 8080，同时监听本机/局域网；H5 使用独立的 `VITE_H5_API_BASE`，不受微信 `VITE_API_BASE` 残留值影响；后台幂等键兼容普通 HTTP 缺少 `crypto.randomUUID()` 的环境。按用户最新要求，所有模式恢复至少 12 个字符的严格密码校验，不合规时启动失败；四个角色采用独立配置，当前密码为各自账号名加 `12345678`。`DEMO_SYNC_PASSWORDS=true` 时重启同步既有演示账号，生产不自动同步。账号与配置字段见 [本机测试账号](local-test-accounts.md)。
