## 分类与紧急程度口径

| 分类 | 暂定判定边界 | 项目分类代码 |
| --- | --- | --- |
| 管道维修 | 建筑供排水管线、阀门、水箱及卫浴给排水附件；以已经描述的漏点或堵点为依据 | PLUMBING |
| 水电维修 | 建筑固定供电线路、开关插座、配电设施和公共照明；名称虽包含“水”但本批供排水问题统一归管道 | ELECTRIC |
| 家电维修 | 独立家用电器、设备内部管线、自带电源线及附属部件；不把外部停水停电归为家电故障 | APPLIANCE |
| 其他维修 | 门窗五金、建筑饰面、公共设施、电梯、道闸等其余对象 | OTHER |

分类按主要故障对象判断，不按句中第一个设备名、次生危害或维修人员工种判断。例如给水管喷水到配电柜暂归管道，插座冒烟暂归水电。若存在多个独立故障而无法选择主要对象，应修改描述为单一明确场景或排除，不能在单标签列中填多个答案。附属软管、安装支架、门禁等责任边界已在相应行注明，需审核人统一口径。电梯和公共机电设施归“其他”只是当前四分类体系的映射，不表示可以由普通维修人员处理。

| 紧急程度 | 暂定判定口径 |
| --- | --- |
| NORMAL | 局部、可控，主要功能仍可用，描述中没有明确即时风险 |
| HIGH | 明显影响基本使用、公共服务或损失持续扩大，但没有描述即时危险 |
| URGENT | 描述中已有即时人身或重大财产风险，例如明火、持续打火、实际被困、构件正在坠落或失控淹水威胁运行设备 |

用户催促、感叹号、出现“消防”等字样不能单独决定等级；以影响、危险事实和是否受控为依据。同一种设备可因场景不同落入三种等级。**未描述风险不等于已排除风险**：信息不足行的 NORMAL/HIGH 不是安全结论，须补全信息或排除。案例不提供现场处置或危险维修步骤，不能作为实际应急操作指南。

## 逐条审核

| 字段 | 用途及填写规则 |
| --- | --- |
| 编号 | R001～R120，保持唯一；引用和讨论均使用编号 |
| 报修描述 | 未来发给模型的唯一案例文本；需要补充时可在审核阶段修改并在审核备注保留原文及修改原因 |
| 场景类型 | 清晰描述／口语表达／边界案例／信息不足；补全描述后如性质改变需相应调整 |
| 建议分类、建议紧急程度 | AI 起草的参考标签，不是标准答案；保留原值以便对照 |
| 建议依据、歧义说明 | 说明暂定判断及缺失事实，不应作为模型输入 |
| 人工分类 | 由人填写四种分类之一；即使同意建议也必须填写 |
| 人工紧急程度 | 由人填写 NORMAL／HIGH／URGENT；即使同意建议也必须填写 |
| 审核状态 | 初始统一“待审核”；审核后填“已确认”“需补充”或“已排除” |
| 审核备注 | 记录标签修改、描述补充或排除原因；记录审核人代号及审核日期 |

人工分类、人工紧急程度和审核备注初始均为空；审核状态按方案统一预填“待审核”。

建议先隐藏建议标签、建议依据和歧义说明，阅读描述后独立填写人工判断，再对照参考说明检查边界。审核期间不查看待评测模型的预测结果，避免用模型输出反推标准答案。候选标签来源是 AI，即使经人工确认，最终报告也应写明“AI 起草候选案例，经人工复核定标”。

1. 明确且可确定标签：填写两个人工标签及审核信息，状态改为“已确认”。
2. 需要补充事实：状态改为“需补充”，注明缺什么；补全并重新审核后才能确认。不得凭空认定未提及的烟火、被困或泄漏已不存在。
3. 不合理、重复、无法单标签定标或不属于本次范围：状态改为“已排除”，写明原因。

**进入正式评测的条件：状态为“已确认”，两个人工标签均合法，审核人和日期可追溯，描述不存在尚未解决的标注歧义。** 未审核的行不能通过复制建议标签自动转为已确认。不同意建议时直接填写人工标签，无需保持原始等级比例。

## 冻结及后续评测

本轮只交付候选集，不生成正式标准答案文件。人工审核结束后，以确认记录生成独立的冻结数据集和版本说明，保留候选原稿、审核历史、来源、审核日期及文件 SHA-256。冻结后不原地改写；修改标签或文本须发布新版本。

若有效确认样本少于 120 条，先补充候选案例并经人工复核，再冻结 120 条；不得用待审核样本填满。报告中的分类和等级分布以最终人工标签为准，不能沿用候选分布。

真实评测时只向 `/api/ai/repair-analysis` 发送“报修描述”，不得发送参考答案、场景类型、建议依据或人工备注。类别通过运行环境的分类字典按代码／名称映射，不假定数据库数字 ID 永远不变。标准答案只取人工列。实际评测的执行脚本、模型调用和结果报告不属于本次交付。

这是一批人为安排覆盖面的合成案例，可用于分场景能力评测，**不代表实际报修分布，不能据此推断线上总体准确率**。相似主题和口语变体存在关联；后续若用于调优和测试，应按故障主题分组，避免近似案例同时进入调优集与独立测试集。本批中的危险场景是对已有风险描述的识别测试，不是危险发生概率估计。
